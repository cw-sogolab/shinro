# 입시 데이터 정합성 점검 결과와 클렌징 플랜

2026-11-04 갱신 · 대상: 2017~2026 원본 엑셀 10개 (2020~2026 7개는 점검 완료 89,291행, 2017~2019 3개는 받음)

**범위: 학부(学部)만.** 대학원·단기대·별과는 마트에 넣지 않는다.

## 0. 구조: 「마트 테이블」 하나를 먼저 만든다

지금은 curves.py·schools_export.py·results_export.py 가 각자 원본 엑셀을 읽고 각자 정리한다. 정리 규칙이 세 군데에 흩어져 있고, 규칙을 바꾸면 세 개를 다 다시 돌려야 한다.

바꾼다: **원본 → (한 번) 클렌징 → 마트 테이블 → 각 계산은 마트만 읽음.**

```
원본 엑셀 2017~2026 (10개)
  + 규칙 시트 3개 (학부 계보 · 연도별 요강 규칙 · 학부별 예외 판단)
        │  tools/build_mart.py  (양식 통일 → 이름 통일 → 플래그 부여)
        ▼
data/mart/admissions.parquet  (+ 같은 내용 xlsx 1개: 사람이 열어 보는 용도)
        │
        ├─ curves.py        → curves.js   (합격 곡선)
        ├─ schools_export   → schools.js  (학교 찾기)
        └─ results_export   → results.js  (입시 결과)
```

마트 한 줄 = 지원 기록 하나. 열:
연도 · 학교(통일) · 학부(통일, 계보 적용) · 학과 · 학교 원표기 · 학부 원표기 · 합부 · 6월 8과목 · 11월 8과목 · TOEFL · TOEIC · 조합(6월/11월) · 계열 · 총점(6월/11월) · **플래그** · 원본 파일 · 원본 행

- 계산 파일(curves.py 등)은 **원본을 다시 읽지 않는다.** 플래그를 보고 어떤 줄을 쓸지만 정한다.
- 규칙을 고치면 build_mart.py 한 번만 돌리면 된다. 새 해 원본이 오면 그 파일만 추가하고 한 번 돌린다.
- 마트에는 이름·수험번호가 없다(원본에도 없음). 그래도 합격 데이터라 저장소에는 올리지 않고 드라이브 「진학상담_데이터」에 둔다.
- 마트가 생기면 사이트 화면도 마트의 플래그 수를 그대로 보여 줄 수 있다(「검증된 점수 m명 · 의심 k명」).

## 2. 왜 이런 데이터가 되나
- 여러 학원이 기관에 제출한 자료를 합친 것이라 입력 기준이 제각각이다.
- 합격 여부만 적고 점수를 안 적거나, 6월·11월 중 한 회차만 적는다.
- 한 학생이 여러 학과에 지원하면 같은 점수가 여러 줄로 들어가고, 제출이 겹치면 통째로 중복된다.
- 고득점자가 안전 지원한 하위권 대학 합격 기록은 실제로 있는 일이다. 틀린 데이터는 아니지만 「그 학교 수준」을 보여 주지 않는다.

## 3. 클렌징 플랜

원칙: **지우지 말고 표시한다.** 각 행에 「검증 결과」 열을 두고, 화면과 곡선이 어떤 행을 쓸지 규칙으로 정한다. 그래야 나중에 규칙을 바꿔도 원본을 다시 만들 필요가 없다.

### 3-1. 1단계 · 양식 통일 (원본 10개 → 마트 1개)
- 열 이름을 하나로 맞춘다: 연도, 대학코드, 학교, 학부, 학과, 구분(学部/院/短大/別科), 합부, 6월 8과목, 11월 8과목, TOEFL, TOEIC.
- 합부는 1/0 두 값만. ×→0, 〇→1, 빈칸→「미상」으로 표시.
- 기호(※ ＊ 공백)는 점수가 아니므로 빈칸으로 바꾸고 「기호」 열에 원래 기호를 남긴다. **※와 ＊의 뜻을 원장님께 확인**(미응시? 제출 안 함? 점수 비공개?).
- 학교·학부 이름 사전(별도 시트)으로 표기를 통일한다. 단기대학부는 그대로 둔다.
- 이 단계는 스크립트가 자동으로 하고, 매년 새 원본이 오면 다시 돌린다.

### 3-2. 2단계 · 자동 검증 규칙 (행마다 플래그)
| 플래그 | 규칙 | 처리 |
|---|---|---|
| 중복 | 같은 연도·학교·학부·학과·합부·점수 전부 같음 | 한 줄만 남김 |
| 점수없음 | 6월·11월 모두 비어 있음 | 인원 집계에만 사용 |
| 조합불일치 | 2027 요강이 있는 학부: 요강이 인정하는 과목 조합이 아님. 요강 없는 학부: 그 학부 합격자 다수 조합(85% 이상)과 다르고 소수(15% 미만) | 점수 통계·곡선에서 제외, 인원에는 포함 |
| 영어증빙없음 | 영어가 **요강에서 필수(R)인 학부**인데 TOEFL·TOEIC 없음. 요강이 없는 학부만 지금의 추정 규칙(합격자 60% 이상 기재)을 쓰고, 추정으로 잡힌 것은 「추정」 표시 | 곡선에서 제외. 영어가 선택·불필요인 학부는 플래그 안 붙음 |
| 수준이탈 | 지원자 총점이 그 학교 합격자 중앙값보다 150점 이상 높음 (안전 지원) | 곡선은 그대로 사용(상단은 어차피 합격), 「최고점」 표시에서는 제외 |
| 점수이상 | 로버스트 z ≥ 3.5 | 점수 통계·곡선에서 제외 |
| 범위밖 | 과목 만점 초과, 일본어 50점 미만 | 그 칸만 비움 |

### 3-3. 3단계 · 사람 검토
- 플래그가 붙은 행만 모은 「검토 시트」를 엑셀로 만든다 (학교·학부·연도·점수·플래그·판단 칸).
- 수가 많은 「조합불일치」(5,769건)는 학부별로 묶어 보여 주고, 학부 단위로 「이 학부는 일본어만으로도 지원 가능」 같은 판단을 적게 한다. 한 줄씩 보지 않아도 된다.
- 판단 결과는 「규칙 예외 시트」에 남겨서 다음 해에도 자동 적용된다.

### 3-4. 4단계 · 검증
- 규칙 적용 전·후로 2022~2025 → 2026 예측 정확도(구간별 실제 합격률)를 비교한다. 좋아지지 않는 규칙은 뺀다.
- 「계산 방법」 탭에 전·후 수치를 같이 보여 준다.

### 3-5. 화면 반영
- 입시 결과 탭: 「지원 n명 (검증된 점수 m명 · 의심 k명 제외)」을 표마다 표시.
- 최고·최저 총점자 대신 상위 25% / 중앙 / 하위 25%를 기본으로 보여 주고, 최고·최저는 펼쳐서 본다. 고득점 안전 지원 한 명이 그 학교의 인상을 바꾸지 않게 한다.
- 학교 찾기·추천: 곡선을 만든 인원과 제외한 인원을 「자료 n명」 옆에 같이 적는다.

### 3-7. 연도별로 필수 과목이 다른 학부
지금은 2027 요강 하나를 모든 연도에 적용한다. 요강이 바뀐 학부는 옛 합격자가 통째로 빠지거나 잘못 섞인다.

**「연도별 요강 규칙표」**를 둔다. 학부마다 적용 연도 범위가 있는 줄을 여러 개 둘 수 있다.

| 학교 | 학부 | 적용 연도 | 인정 조합(여러 개 가능) | 근거 |
|---|---|---|---|---|
| 와세다 | 사회과학 | 2017~ | 일본어+종합+수학1 | 2027 요강 |
| ○○대 | 경영 | 2020~2023 | 일본어+종합 | 다수 패턴(자동 추정) |
| ○○대 | 경영 | 2024~ | 일본어만 | 2027 요강 |

- 검증은 **그 행의 연도에 맞는 규칙**으로 한다.
- 규칙표 채우기: 학교·학부별로 연도마다 합격자 조합 분포를 뽑고, 다수 조합이 바뀌는 해를 경계로 자동 분할 → 가장 최근 구간이 2027 요강과 맞는지 확인 → 사람이 경계 연도·조합을 확정. 자동 추정은 표시만, 확정된 것만 규칙으로 쓴다.
- 「선택 과목」 학부(종합 또는 수학 중 하나)는 조합이 여러 개이므로, 인정 조합을 여러 개 허용하는 형식이어야 한다.
- 사이트 반영: 입시 결과 탭은 고른 연도 규칙으로 거르고 옛 기준 기록에 「옛 요강 기준」 표시. 합격 곡선은 요강이 바뀐 학부는 **바뀐 뒤 연도만** 쓴다(자료가 줄면 참고용으로 떨어지는 것이 맞다). 학교 찾기는 2027 기준 연도의 합격자만 비교.

### 3-8. 학부 이름이 바뀐 경우 (개편·통합·분리)
데이터에서 확인한 실제 예 (2020~2026, 지원 15명 이상 학부):
- 이름만 바뀜: 東京理科大学 理工(~2022) → 創域理工(2023~), 流通経済大学 社会(~2023) → 共創社会(2024~), 帝京平成大学 現代ライフ(~2021) → 人文社会(2022~), 秋田大学 理工(~2024) → 総合環境理工(2025~)
- 분리: 関西学院大学 理工(2020) → 理 / 工 / 生命環境(2021~), 大阪産業大学 工·デザイン工(~2024) → システム工 / 建築環境デザイン / 情報デザイン(2025~)
- 사라진 학부 18곳, 새로 생긴 학부 54곳, 자동으로 찾은 「짝 후보」 21쌍

**처리 방법**
1. 자동 후보 찾기: 같은 학교에서 「어느 해에 사라진 학부」와 「그 해 또는 다음 해에 새로 생긴 학부」를 짝으로 올린다. 이름 글자가 겹치면(理工→創域理工) 점수를 올리고, 합격자 점수대·과목 조합이 비슷하면 또 올린다.
2. 사람이 확정: 후보 21쌍 정도는 한 번에 볼 수 있는 양이다. 「학부 계보 시트」에 ○/× 와 관계(이름 변경 / 분리 / 통합)를 적는다. 모집요강 PDF에 「○○학부(구 △△학부)」 표기가 있으면 그것이 근거가 된다.
3. 계보 시트 형식: 학교 · 옛 학부 · 옛 학부 마지막 연도 · 새 학부 · 관계. 새 학부가 여러 개(분리)면 줄을 여러 개 둔다.
4. 적용 규칙:
   - **이름 변경**: 하나의 학부로 이어 붙인다. 화면에는 현재 이름으로 보이고 「2022까지 理工」 같은 꼬리표를 단다. 곡선도 이어서 만든다(단, 3-7의 과목 규칙이 같을 때만).
   - **분리**: 옛 학부 기록은 새 학부 어느 쪽에도 넣지 않는다(어느 쪽 지원인지 모르므로). 입시 결과 탭에서는 「옛 理工 (2020까지)」로 따로 보여 주고, 곡선은 새 학부 연도만 쓴다.
   - **통합**: 옛 학부 여러 개를 새 학부 하나로 이어 붙이되, 과목 규칙이 같은 것만.
5. 2027 요강과 입시 데이터를 맞출 때(yoko_rule.py)도 이 계보 시트를 먼저 거친다. 지금은 이름 앞부분이 같아야만 맞춰지므로, 理工→創域理工 같은 경우는 요강이 없는 학부로 취급되고 있다.

### 3-6. 순서와 시간
1. 양식 통일 스크립트 + 검토 시트(플래그 행·학부 계보 후보·연도별 규칙 후보) 생성 — 1~2일
2. 규칙 적용 + 전·후 정확도 비교 — 1일
3. 검토 시트 판단 (원장님·진학 담당) — 학원 쪽 작업
4. 화면 반영 (품질 표시·사분위) — 1일

## 4. 결정이 필요한 것
1. ※·＊·공백 기호의 뜻

## 5. 이 문서의 용어

- **플래그(표시)**: 자동 검증 규칙에 걸린 줄에 붙이는 꼬리표. 「중복」「점수없음」「조합불일치」「영어증빙없음」「수준이탈」「점수이상」 여섯 가지. 줄을 지우지 않고 꼬리표만 붙여 두고, 곡선·통계·인원 집계가 각자 어떤 꼬리표까지 쓸지 정한다. 「플래그 행」 = 꼬리표가 하나라도 붙은 줄.
- **수준이탈**: 지원자 점수가 그 학교 합격자 중앙값보다 150점 이상 높은 기록. 예: 류쓰카가쿠 상학부 합격자 중앙값 418점인데 678점 지원자. 틀린 데이터가 아니라 고득점자의 안전 지원이다. 다만 이 한 명 때문에 화면의 「최고 합격 점수」가 678점으로 보이면 학교 수준을 오해하므로, 최고점 표시에서만 뺀다. 곡선에는 그대로 쓴다(점수가 높으면 합격이라는 사실 자체는 맞으므로).
- **조합**: 한 회차에 응시한 EJU 과목의 묶음. 일본어+종합+수1 / 일본어+이과2+수2 / 일본어만 등.
- **다수 조합**: 그 학부 합격자가 가장 많이 낸 조합. 85% 이상이면 「이 학부는 이 조합을 요구한다」로 본다.
- **로버스트 z**: 평균·표준편차 대신 중앙값·MAD(중앙값 절대편차)로 잰 「얼마나 동떨어졌나」. 극단값 자체에 덜 흔들린다. 3.5 이상이면 점수이상.

## 6. 용어를 설명할 수 있게 되는 방법

### 6-1. 용어집 만들기
용어마다 네 줄로 정리한다: ① 한 줄 정의 ② 어떻게 계산하는지 ③ 학생·학부모에게 말하는 문장 ④ 흔한 오해.

예시 — **반반 점수**
- 정의: 그 학부의 합격 곡선에서 합격 가능성이 딱 50%가 되는 총점.
- 계산: 곡선 식 p = 1/(1+e^-(a+b·점수+보정)) 에서 p=0.5가 되는 점수. 즉 -(a+보정)/b.
- 말하기: "이 점수대 지원자 중 절반이 붙었어요. 여기보다 높으면 붙을 확률이 절반을 넘어요."
- 오해: 「커트라인」이 아니다. 반반 점수보다 낮아도 붙고, 높아도 떨어진다. 「만점 넘음」은 곡선이 너무 완만해서 50%에 닿는 점수가 실제 만점 밖에 있다는 뜻.

정리할 용어: 합격 가능성, 안정·적정·도전·15% 미만, 반반 점수, 참고용(AUC 0.5 미만·자료 적음), 하한·평균·상한, 변환점수·등가점수, 연도 보정값, 영어 충족·미달·제출 가능, 자료 n명, 2027 요강 기준 선별.
