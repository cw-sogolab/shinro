# 입시 데이터 마트를 만드는 과정

도구: `tools/build_mart.py` · 같이 쓰는 것: `tools/yoko_rule.py`(2027 모집요강 규칙)
결과물은 합격 데이터라 저장소에 올리지 않고 드라이브 「진학상담_데이터」에 둡니다.

## 왜 마트인가
예전에는 합격 곡선(curves.py)·학교 찾기(schools_export.py)·입시 결과(results_export.py)가 각자 원본 엑셀을 읽고 각자 정리했습니다. 정리 규칙이 세 군데에 흩어져 있어 규칙 하나를 바꾸면 셋을 다 다시 돌려야 했습니다.

이제는 **원본 → 마트(한 번 정리) → 각 계산**입니다. 계산 파일은 원본을 다시 읽지 않고 마트만 읽습니다. 새 해 원본이 오면 그 파일을 폴더에 넣고 마트만 다시 만들면 됩니다.

```
원본 엑셀 2017~2026 (연도별 1개)            원장님 검토 엑셀 (판단 적힌 것)     2027 모집요강
              └──────────────┬───────────────────────┘                        │
                    tools/build_mart.py  ◀───────────────────────────────────┘
                             │
   admissions_mart.csv.gz / .xlsx   admissions_rules.csv   원장님_검토_입시데이터.xlsx   build_log.txt
                             │
         curves.py · schools_export.py · results_export.py  (다음 단계: 마트만 읽도록 바꿈)
```

## 실행
```
python3 tools/build_mart.py --raw <원본 폴더> --yoko docs/assets/yoko.js --out <출력 폴더> [--review <판단 적힌 검토 엑셀>]
```
- `--raw`: 파일 이름에 연도(20xx)가 들어간 엑셀. 내용이 똑같은 파일이 두 개 있으면 하나만 씁니다.
- `--review`: 원장님이 판단을 적어 돌려준 검토 엑셀. 없으면 판단 없이(자동 규칙만으로) 만듭니다.

## 단계

### 1. 원본 읽기 — 해마다 다른 양식을 하나로
| 다른 점 | 처리 |
|---|---|
| 열 이름: 日本語 / 日語 / 1日本語 / 日本語-1, コース1 / 数1 / コ1-1 … | 「受験校」 열 위치와 「日本語」가 들어간 두 열(첫째 = 6월, 둘째 = 11월)을 찾아 그 뒤 8칸을 일본어·기술·물리·화학·생물·종합·수학1·수학2로 읽음 |
| 구분 열: 区分1 / 備考1 / 分類1 / 区1 | 이름 앞부분으로 찾음 |
| 합부 열: 2024는 「合否」가 두 개 | 값이 더 많이 찬 열을 씀 |
| 합부 값: 0·1 외에 〇·× (2020) | 〇→합격, ×→불합격. 그 밖의 값·빈칸은 제외 |
| 점수 칸의 ※·＊·공백 | 점수는 빈칸으로 두고, 원래 기호를 「기호_원값」에 보관 + 플래그 「기호」 |
| 만점 초과·음수·일본어 50점 미만 | 점수는 빈칸, 원래 값은 「범위밖_원값」 + 플래그 「범위밖」 |
| 원본 위치 | 모든 행에 「원본파일」「원본행」을 남겨 원본으로 되짚을 수 있게 함 |

### 2. 학부만 남기기
- 구분이 院·短大·別科·短大別科이면 제외.
- **2017·2018은 구분 칸이 대부분 비어 있음.** 빈칸은 학부로 보되, 학교 이름에 「大学院大学」이 있거나 학부 이름에 「研究科」가 있으면 院, 학교 이름에 「短期大学」가 있으면 短大로 보고 제외.

### 3. 이름 통일과 학부 계보
- 학교·학부·학과 이름을 NFKC 정규화(전각/반각 통일)하고 공백을 뺌.
- 학부 끝의 「学部」, 학과 끝의 「学科」를 떼어 같은 학부·학과로 묶음 (예: 北海道大学 「理」와 「理学部」). 원래 표기는 「학부_원표기」「학과_원표기」에 남김.
- **학부 계보 후보**: 같은 학교 안에서 「어느 해부터 없어진 학부」와 「그 해~3년 안에 처음 나타난 학부」를 모두 짝지음 (지원 1명 이상 전부). 단서점수 = 이름이 포함 관계(+2), 이름 글자가 겹침(+1), 같은 학과 이름이 있음(+2), 바로 다음 해 등장(+1).
- 원장님이 「이름변경」·「통합」으로 판단한 짝은 **옛 학부 기록을 새 학부 이름으로 합칩니다.** 「학부_계보」 열에 「옛→새」를 남깁니다. 「분리」는 옛 기록을 따로 둡니다.
- 같은 대학코드에 이름이 둘 이상이거나 같은 이름에 코드가 둘 이상인 경우는 검토 엑셀 「학교명」 시트로.

### 4. 과목 조합과 계열
회차(6월·11월)마다:
- **조합**: 응시한 과목 묶음 (예: 일본어+종합+수1, 일본어+이과2+수2).
- **계열**: 종합을 봤으면 문과, 이과 과목을 봤으면 이과, 둘 다 없으면 일본어만, 일본어가 없거나 종합·이과를 둘 다 봤으면 기타.
- **총점**: 문과 = 일본어+종합+수1, 이과 = 일본어+이과 상위 2과목+수2, 일본어만 = 일본어. 기술은 넣지 않음. 11월 총점이 있으면 11월, 없으면 6월.

### 5. 연도별 과목 규칙 (학부 / 학과)
2027 요강 하나를 모든 해에 적용하지 않고, **해마다 합격자가 실제로 낸 과목으로 그해의 규칙을 추정**합니다.
- 규칙 = 「인정하는 계열」(그 계열 합격 기록이 10% 이상·2건 이상) + 「계열 안의 필수 과목」(그 계열 합격 기록의 85% 이상이 낸 과목: 문과 수1, 이과 수2·이과 2과목).
- 단위: 학부. 단, 학과가 둘 이상인 학부에서 합격 기록이 30건 이상인 학과는 **학과 단위로 따로** 규칙을 만듭니다 (같은 학부라도 학과마다 과목이 다를 수 있으므로).
- **현재 규칙의 시작 연도**: 최근 연도부터 거꾸로 합격 기록 15건이 모일 때까지 모아 「기준 규칙」을 만들고, 그 전 해들을 하나씩(합격 기록 8건 이상인 해만) 기준과 비교해 분명히 다른 가장 최근 해의 다음 해를 시작 연도로 봅니다. 분명히 다르다 = 한쪽에서 25% 이상인 계열이 다른 쪽에서 5% 이하, 또는 필수 과목이 다름.
- 이전 구간과 현재 구간의 규칙 내용(인정 계열·필수 과목)이 결국 같으면 바뀐 것으로 보지 않습니다.
- 원장님이 「확정 시작 연도」를 적으면 그 연도를 씁니다.
- 각 행에 「규칙구간」(현재/이전)과 「규칙단위」(학부/학과)를 적습니다. **합격 곡선은 현재 구간 기록만 씁니다** (지금 기준이 제일 중요하므로).
- 2027 요강은 비교용으로만 씁니다: 「요강허용」(그 행의 계열을 2027 요강이 인정하는지)과 admissions_rules.csv의 「요강2027」. 데이터 규칙과 요강이 다른 곳은 검토 엑셀에서 볼 수 있습니다.

### 6. 플래그
행을 지우지 않고 꼬리표만 붙입니다. 한 행에 여러 개 붙을 수 있습니다(「;」로 구분).

| 플래그 | 규칙 |
|---|---|
| 중복 | 연도·학교·학부·학과·합부·모든 점수·영어 점수가 똑같은 행의 두 번째부터 (점수가 하나라도 있는 행만) |
| 점수없음 | 6월·11월 점수가 모두 없음 |
| 기호 | 점수 칸에 ※·＊·공백 같은 기호가 있었음 |
| 범위밖 | 만점 초과·음수·일본어 50점 미만이 있었음 (그 칸은 빈칸 처리) |
| 조합불일치 | 그 해(규칙 구간)의 규칙이 인정하지 않는 계열이거나 필수 과목이 빠짐. 원장님이 그 조합을 「인정」하면 붙지 않음 |
| 영어증빙없음 | 2027 요강에서 영어가 **필수(R)인 학부**인데 TOEFL·TOEIC이 없음 (현재 규칙 구간만). 요강에 없는 학부는 합격자 60% 이상이 영어 점수를 냈으면 필수로 추정하고 「영어증빙없음(추정)」. 영어가 선택·불필요인 학부는 붙지 않음 |
| 수준이탈 | 같은 학부·같은 계열 합격자 중앙값(10건 미만이면 같은 학교·같은 계열)보다 **100점 이상** 높음 |
| 점수이상 | 같은 학부·합부·계열(8건 이상) 안에서 로버스트 z 3.5 이상 |

**사람이 판단하면 플래그가 없어지나?** 판단은 플래그를 지우지 않고 계산 방식을 바꿉니다. 「조합불일치」는 원장님이 그 조합을 「인정」하면 애초에 붙지 않습니다. 「학부 계보」는 판단이 있으면 기록이 새 학부로 합쳐집니다. 그 밖의 플래그(기호·수준이탈 등)는 판단할 필요 없이 그대로 두고, 계산·화면에서 넣을지 뺄지 정합니다. 판단은 검토 엑셀에 남아서 내년에 새 원본을 넣고 다시 만들어도 계속 적용됩니다.

### 7. 출력
- `admissions_mart.csv.gz` / `.xlsx`: 마트. 열 = 연도 · 대학코드 · 학교 · 학부 · 학과 · 학부_원표기 · 학과_원표기 · 학부_계보 · 구분2(추천·AO 등) · 합부 · 합부_원값 · 6월/11월 8과목 · TOEFL · TOEIC · 조합·계열·총점(6월/11월) · 총점 · 계열 · 규칙단위 · 규칙구간 · 요강허용 · 영어기준 · 비교중앙값 · 플래그 · 기호_원값 · 범위밖_원값 · 원본파일 · 원본행
- `admissions_rules.csv`: 학부·학과마다 데이터 연도, 현재 규칙 시작, 현재·이전 규칙, 2027 요강, 연도별 규칙.
- `원장님_검토_입시데이터.xlsx`: 사람이 판단할 것만 (학부계보 · 규칙변경 · 소수조합 · 학교명).
- `build_log.txt`: 단계별 건수.

## 계산 쪽에서 권하는 사용법 (기본값)
| 용도 | 쓰는 행 |
|---|---|
| 지원·합격 인원 | 「중복」 아닌 행 |
| 점수 통계(평균·분포) | 「중복·점수없음·조합불일치·점수이상」 아닌 행. 「기호」는 화면에서 넣을지 고름 |
| 최고 합격 점수 표시 | 위 + 「수준이탈」도 뺌 |
| 합격 곡선 | 점수 통계와 같음 + 「영어증빙없음」 뺌 + **규칙구간 = 현재** |
