# 진학 상담 디자인 시스템 — 사용 규칙

> 의뢰서: `../DESIGN_BRIEF.md` · 결정(현채원 강사, 2026-10-22): 일공 로고 톤(검정·빨강) · 브랜드는 일공학원 · 학생에게 예측 점수를 보여주되 부드러운 톤

일공학원 진학 상담 사이트(학생 카드 · 예측 · 추천 · 출원 관리 · 학교 정보)의 디자인 시스템. 로고의 **흰 바탕 · 검정 워드마크 · 빨간 O**를 화면 규칙으로 옮겼다. 순수 HTML·CSS·JS — `tokens.css` + `components.css`(= `components/bundle.css`) + `ilgong.js`(= `components/bundle.js`)를 붙이면 된다.

## 원칙

1. **검정이 구조, 빨강은 '지금 손대야 할 것'.** 주 버튼·선택된 메뉴·핵심 숫자 하나는 검정(`inverse`). 빨강(`brand`)은 D-7 이내 마감, 뒤처진 지원 건, 처리할 건수, 위험 동작에만. 합격 가능성·구간·불합격에는 빨강을 쓰지 않는다.
2. **O는 신호다.** 로고의 빨간 링은 `Ring`으로 화면에 남는다. 링이 보이면 그 학생·건을 봐야 한다. 선 두께는 언제나 지름의 1/5.
3. **예측은 범위로, 가능성은 비율로.** 점 하나만 보여주지 않는다. 「합격」을 단정하지 않는다.
4. **같이 보는 화면.** 학생 카드는 학생·학부모가 옆에서 본다. 숫자는 크고 굵게, 문장은 짧게, 경고는 조용하게.
5. **카드는 명도로 뜬다.** `canvas` 위 `surface` 카드(`radius-xl`). 그림자·색 테두리로 강조하지 않는다.

## 문구

- 「합격 가능성」 = 과거 비슷한 점수 지원자 중 합격한 비율. ✕ 「합격 확률」「붙는다」「합격 예상」「AI 합격 예측」.
- 예측: 「예상 612점 (보통 580~645)」. ✕ 「612점 나옵니다」.
- 90% 이상은 「90%+」(`Ilgong.pct`). 표본 부족은 확률 대신 「합격자 590~680점 · 7명」.
- 모든 예측·추천 화면에 고정: 「참고용 · 합격을 보장하지 않음 · 합격 가능성은 과거 비슷한 점수 지원자 중 합격한 비율입니다.」 — `Disclaimer`, 굵게·빨강·상자 금지.
- 모집요강 요약 항목마다 「원문 N쪽」(`.ig-src`). 마감에는 「필착」/「소인 유효」와 「일본 시간」.
- 버튼은 동사로 끝낸다: 「지원 건으로 추가」「단계 넘기기」「상담 요약 인쇄」. 날짜 `10월 22일 (목)`, 수치 `612점`, `-2%p`, `7건`. 이모지 없음.

## 의미 색 (색만으로 구분하지 않는다 — 항상 글자, 가능하면 모양도)

| 의미 | 토큰 | 모양·글자 | 쓰는 곳 |
| --- | --- | --- | --- |
| 안정 (70%+) | `zone-safe` · `-soft` | 꽉 찬 원 + 「안정」 | 추천 목록, 곡선 띠, 요약 칩 |
| 적정 (40~70%) | `zone-fit` · `-soft` | 반원 + 「적정」 | 〃 |
| 도전 (15~40%) | `zone-try` · `-soft` | 빈 원 + 「도전」 | 〃 |
| 참고 (표본 부족) | `zone-ref` | 점선 원 + 「참고」, 확률 없음 | 〃 |
| 점수 외 요소 큼 | `zone-ref` | 회색 테두리 태그 | 곡선이 완만한 학부 |
| D-day 7일 이내 | `brand` / `on-brand` | 빨강 채움 「D-3」 | 마감 보드, 타임라인 |
| D-day 30일 이내 · 진행 중 · 그 이후 · 지남 | `warning-soft` · `ink` 테두리 · `surface-muted` · 취소선 | 「D-18」「접수 중」「D-44」「지남」 | 〃 |
| 뒤처진 지원 건 | `brand` | 왼쪽 빨간 선 + Ring + 「뒤처짐」 | 마감 보드, 지원 건 |
| 단계 9개 | `ink` | 숫자 원 → ✓ | 스테퍼 |
| 합격 / 불합격 | `success` / `ink-muted` | 「합격」 / 「불합격」(회색) | 결과 |
| 서류 필수 / 일부 필수 / 해당자 / 임의 | `inverse` / `ink` 테두리 / `info-soft` / 회색 테두리 | 채움 · 테두리 · 파랑 · 옅은 테두리 | 체크리스트 |
| 한국 학생 해당 | `kr` · `kr-soft` | 「한국 학생」 | 모집요강 요약 |
| 원문 확인 필요 | `warning` | 점선 테두리 「원문 확인 필요」 | 모집요강 데이터 |
| 개발판 / 데모 띠 | `band-dev` / `warning-soft` 빗금 | 「[개발판] …」 / 「데모 · …」 | 화면 맨 위 |
| 본인 / 반 평균 / 예측 범위 | `me` / `avg` / `pred-band` | 실선 / 점선 / 띠(인쇄: 빗금) | 성적 추이 |

`me`·`avg`는 성적노트와 같은 이름이다. 값은 이 시스템에서 검정·회색(성적노트는 파랑) — 성적노트를 이 톤으로 옮기면 그대로 맞는다.

## 색 · 글자 · 간격

- 바탕 `canvas`, 카드·표·입력 `surface`, 표 머리·hover `surface-hover`, 트랙·칩 `surface-muted`, 구분선 `line`, 입력 테두리 `control-border`.
- 글자 `ink` · 보조 `ink-muted` · placeholder `ink-subtle`(surface 위만). 빨간 글자는 `danger`.
- 서체 **Pretendard Variable**(`font-sans`, 시스템 글꼴 fallback 포함). 일본어 학교·학부 이름은 `lang="ja"` + `.ig-jp`(`font-jp`: Hiragino Sans → Noto Sans JP → Yu Gothic → Meiryo) — 일본식 한자 모양이 나온다. 반각 가나(ﾃﾞｻﾞｲﾝ)는 NFKC로 정규화한 뒤 표시. 학교 칸은 한국어 이름(굵게) 위, 원어 아래(`.ig-school`).
- 단계: `kpi` 36 → `title` 24 → `heading` 18 → `subheading` 15 → `body` 14 → `label` 13 → `caption` 12. 숫자는 전부 tabular-nums(`.ig-num`, `td.num`).
- 간격 4px 단위: 카드 안 `space-5`, 카드 사이 `space-4`, 섹션 사이 `space-6`, 페이지 좌우 `space-6`(휴대폰 `space-4`).
- 모서리: 카드 `radius-xl` 20 · 세그먼트 트랙 `radius-lg` · 버튼·입력 `radius-md` · 작은 버튼·D-day `radius-sm` · 칩·링 `radius-full`.
- 다크 테마는 같은 토큰 이름이 자동으로 바뀐다(`prefers-color-scheme`, 또는 `<html data-theme>`).

## 레이아웃

- 상단 `AppBar`(로고 · 「진학 상담」 · 메뉴 · 로그인 사용자), 본문 최대 `content-max` 1200px.
- 학생 카드: 위에서 아래로 1 성적 추이 → 2 예측 → 3 추천 → 4 지원 건 → 5 메모(`.ig-section-h` 번호).
- 마감 보드: 숫자 타일 4개 → 자동 경고 → 마감일로 묶은 보드. 보기 전환은 마감순·학생별·학교별·담당별.
- 폭 390px부터 깨지지 않는다: 그리드는 한 줄로, 표는 표만 가로 스크롤(첫 열 고정), 보드 행은 세 줄로 접힌다. 페이지 전체 가로 스크롤 금지.

## 학생 화면 (2단계)

- 감싸는 요소에 `.ig-soft`: 합격 가능성 %를 숨기고 구간 칩만, 예측은 `ig-pred--soft`(범위를 파랑으로 앞세움) + 「지금 페이스라면」.
- 본인 성적 · 예측 범위 · 지원 현황 · 서류 체크만. 다른 학생 이름·등수 없음.

## 인쇄 (상담 요약 A4 1장)

- `article.ig-sheet` 하나가 A4 한 장(@page A4, 여백 0, 안쪽 14mm). 앱 바·띠·버튼·토스트는 인쇄되지 않는다.
- 흑백에서 구분: 구간 칩은 모양(꽉 찬·반·빈 원) + 글자, 곡선 띠는 회색·빗금·점 무늬, 예측 범위는 빗금(`#ig-hatch`). 색에만 기대는 표시는 인쇄물에 넣지 않는다.
- 하단 고정 문구: 「참고용 · 합격을 보장하지 않음 · 최종 판단은 상담 강사와 함께 …」. 강사가 확인한 뒤에만 출력.

## 접근성

- 대비 WCAG AA: 모든 글자 토큰은 사용 메모의 바탕 위에서 두 테마 4.5:1 이상, 선·아이콘·테두리 3:1 이상.
- 포커스: `focus-ring` — 바탕색 2px 틈 + `ink` 2px 링. 빨강 포커스 금지.
- 터치 영역 44px 이상(`touch-min`): 버튼·메뉴·세그먼트·체크박스 영역. 작은 버튼도 터치 기기에서 44px.
- 차트는 `role="img"` + 한 문장 `aria-label`. 아이콘만 있는 버튼은 `aria-label`.

## 아이콘 · 로고

- `ilgong.js`가 스프라이트를 넣는다: `<svg class="ig-icon"><use href="#ig-check"/></svg>`. 24 격자·1.75 선·둥근 끝·채움 없음. 없는 것은 같은 규칙으로 Lucide에서.
- 로고: Logos 그룹 `ilgong-logo.png`(밝은 바탕) · `ilgong-logo-reverse.png`(어두운 바탕) · `ilgong-ring.png`(O 심볼). 앱 바에 두 장을 같이 넣으면(`ig-logo--light`/`--dark`) 테마에 맞는 쪽이 보인다. 다시 그리거나 색을 바꾸지 않는다.

## 개인정보

- 견본·스크린샷에는 가상 이름(김하늘·박지우 …)과 `KS-000000 (가상)`만. 실제 학생 이름·수험번호 금지. 견본 화면에는 데모 띠를 붙인다.
- 화면 코드는 공개 저장소에 올라가도 되지만, 학생 데이터·합격 데이터는 로그인 뒤에서만.
