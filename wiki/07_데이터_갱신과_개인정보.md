# 데이터 갱신 방법과 개인정보

> 2026-11-06 개편으로 메뉴가 ① 학교 찾기 ② 예측·추천 ③ 모집요강 ④ 비교 ⑤ 모의고사 분석으로 바뀌었다. 「입시 결과」 탭은 ① 학교 찾기 → 학교·학부 상세 안의 「입시 결과」 칸으로, 「채점 비교」·「계산 방법」 탭은 이 위키로 옮겼다. 아래 본문은 2026-10-22 원장님 보고용 설명을 나눈 것이라 화면 이름이 예전 것일 수 있다.

## 데이터를 새로 반영하는 방법 (강사용)
| 언제 | 할 일 | 명령 (`~/ilgong/shinro` 에서) |
|---|---|---|
| 성적리스트에 새 해 추가 후 (v9 등) | 합격생 점수대 다시 계산 | `python3 tools/schools_export.py --src ".../EJU통합_성적분석_v9.xlsx"` |
| 〃 | 합격 곡선 다시 학습 | `python3 tools/curves.py ...` (단계별 실행 가능) |
| 엑셀 「모델계수」 갱신 후 | 예측 계수 반영 | `python3 tools/model_export.py` (`--check`로 엑셀과 대조) |
| 학생 성적 추가 후 | 학생 찾기 목록 갱신 | `python3 tools/students_export.py` |
| 모의고사 채점 끝난 후 | 모의고사 분석 | `python3 tools/mock_export.py --rounds 1 2 3 4` |
| 모집요강 추가·수정 후 | 검사 + 화면 반영 | `python3 tools/build_yoko.py` |

## 개인정보
- 화면 파일 중 학생 이름이 들어가는 것은 「학생 찾기」 목록(`students.js`) 하나이고, **이 맥에서만** 씁니다(레포 제외, 화면 맨 위 주황 띠로 표시).
- 합격 데이터·모의고사는 **집계만**(이름·수험번호 없음). 그래도 출처와 사용 범위를 원장님이 정하실 때까지 학원 밖·공개 페이지에 올리지 않습니다.
- 정식 운영은 학원 구글 계정 + 로그인 (성적노트와 같은 방식)으로 옮길 계획입니다.

**원장님께 받을 결정**: ① 성적리스트(합격 데이터)의 출처·사용 범위 ② 외부 응시생 성적을 상담에 써도 되는지 ③ 안정 기준 70% 유지 여부 ④ 데이터를 둘 학원 계정과 책임자.
