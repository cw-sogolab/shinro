# ② 예측·추천 — EJU 예측과 합격 곡선

> 2026-11-06 개편으로 메뉴가 ① 학교 찾기 ② 예측·추천 ③ 모집요강 ④ 비교 ⑤ 모의고사 분석으로 바뀌었다. 「입시 결과」 탭은 ① 학교 찾기 → 학교·학부 상세 안의 「입시 결과」 칸으로, 「채점 비교」·「계산 방법」 탭은 이 위키로 옮겼다. 아래 본문은 2026-10-22 원장님 보고용 설명을 나눈 것이라 화면 이름이 예전 것일 수 있다.

### 3-1. 무엇을 예측하나 (자동 선택)
| 학생 성적 | 예측 대상 |
|---|---|
| 6월 EJU가 없음 | **6월 EJU** (모의 1·2회로) |
| 6월 EJU가 있음 | **11월 EJU** (모의 1~4회 + 6월 EJU로) |
| 11월 EJU가 있음 | 예측 없이 **실제 11월 점수** 사용 |
화면에서 수동으로 바꿀 수도 있습니다.

### 3-2. 과목별 예측 공식 (엑셀 「모델계수」 시트 그대로)
1. **회차마다 등가점수**: 그 회차 점수를 「실제 EJU로 치면 몇 점」으로 바꿉니다.
   > 등가점수 = 절편 a + 기울기 b × (입력 점수 − 난이도 보정 δ)
   - a, b: 2025년 학생들의 「그 회차 모의 점수 → 실제 EJU 점수」 회귀식. 인원이 너무 적은 과목(이과 생물)은 평균 차이만큼 옮기는 방식(b=1).
   - δ: 그 회차가 작년 같은 회차보다 얼마나 쉬웠나/어려웠나 (엑셀 「난이도분석」 시트의 2026−2025 난이도 차). 6월 예측은 2025 모델을 그대로 써서 δ=0.
2. **정확도 가중평균**: 회차별 등가점수를 가중치 w = 1 ÷ (그 회차 예측 오차 SD)² 로 평균. 오차가 작은(잘 맞는) 회차를 더 믿습니다. 학생이 안 본 회차는 빠집니다.
3. **11월 상위권 보정**: 회귀식은 상위권을 실제보다 낮게 예측하는 경향(평균으로 끌려가는 현상)이 있어, 11월 예측에만
   > 보정 점수 = c0 + c1 × 원래 예측 (0~만점 사이로 자름)
   - 문과 일본어 c0 = −58.8, c1 = 1.206 / 종합 −40.4, 1.265 / 수학 −42.8, 1.329 (이과도 과목별로 따로).
4. **총점** = 일본어 + 종합 + 수학 (문과), 일본어 + 과학 2과목 + 수학 (이과). 기술 제외.

**예시 학생 (가상, 문과)으로 실제 계산** — 모의 1회 290/130/120 · 2회 305/138/128 · 6월 EJU 318/142/135 · 3회 320/145/140

| 일본어 | 입력 | 등가점수 계산 | 등가점수 | 가중치(×10⁻⁴) |
|---|---|---|---|---|
| 모의 1회 | 290 | 140.8 + 0.612×(290 − 10.9) | 311.6 | 11.81 |
| 모의 2회 | 305 | 122.3 + 0.688×(305 − 32.1) | 310.0 | 13.66 |
| 6월 EJU | 318 | 150.0 + 0.520×(318 − 0) | 315.3 | 11.51 |
| 모의 3회 | 320 | 68.3 + 0.841×(320 − 21.1) | 319.6 | 16.26 |
| **가중평균** | | | **314.4** | |
| **상위권 보정** | | −58.8 + 1.206 × 314.4 | **320.3** | |

같은 방식으로 종합 155.9 → **156.8**, 수학 137.8 → **140.3** → **11월 예상 총점 617점**.

### 3-3. 범위 「보통 574~661」
- 지난 검증에서 예측이 실제와 벌어진 정도(총점 표준편차): **11월 문과 ±43.7점 · 이과 ±34.9점**, 6월 문과 ±50 · 이과 ±41 (엑셀 「오차율요약」).
- 과목별 범위는 이 오차를 과목 오차 크기(일본어 25 · 종합 19 · 수학 17 · 물리·화학 8 · 생물 9) 비율로 나눠 씁니다.
- 「617점 나온다」가 아니라 「예상 617점, 보통 574~661」로 말합니다.

### 3-4. 엑셀과 맞는지
사이트 계산을 엑셀 「11월예측」 시트(LibreOffice로 다시 계산한 값)와 대조: **1,866개 과목 예측(학생 481명)이 소수점까지 일치**. 2026년 6월 실제 점수 대비 평균 오차는 일본어 약 25점, 종합 약 16점, 수학 약 11점.

### 3-5. 추천: 합격 곡선
**데이터**: v8의 최근 5년(2022~2026). 학교·학부·계열마다 **합격 10명 이상 + 불합격 10명 이상**인 곳만 → 377개 학부.

**곡선**: 「점수 → 합격률」을 S자 곡선(로지스틱 회귀)으로 맞춥니다.
> 합격 가능성 = 1 ÷ (1 + e^−(a + b×점수 + 연도 보정))

- **어느 점수로?** 학부가 실제로 무엇을 보는지 모르므로 조합 3가지(J / JS·JR / JSM·JRM) × 회차 3가지(6월 / 11월 / 높은 쪽)를 모두 시험해 **합격·불합격을 가장 잘 가르는 것(AUC)**을 고릅니다. 결과: 일본어만 132개, 일본어+종합 76, +수학1 67, 일본어+이과 21, +수학2 81 학부.
- **연도 보정**: 같은 점수의 합격률이 해마다 떨어지고 있습니다(문과 600~650점대 2022년 47% → 2026년 36%). 그래서 최근 해에 가중치(1 · 0.7 · 0.5 · 0.35 · 0.25)를 더 주고, 연도별 공통 차이를 따로 빼서 곡선을 맞춘 뒤, 다음 해 예측에는 **가장 최근 해(2026) 수준**(보정값 −0.806)을 씁니다.
- **예측 범위 반영**: 학생 점수가 하나가 아니라 범위(3-3절)이므로, 예상 점수 ±2표준편차 안 9개 지점의 합격 가능성을 정규분포 무게로 평균합니다. 실제 점수(11월 EJU)면 범위 없이 계산.
- **반반 점수**: 합격 가능성이 50%가 되는 점수.

**구간**
| 구간 | 합격 가능성 | 2026년 실제 합격률 (검증) |
|---|---|---|
| 안정 | 70% 이상 | 74% |
| 적정 | 40~70% | 52% |
| 도전 | 15~40% | 30% |
| (숨김) | 15% 미만 | 10% |

검증은 「미래를 모르는 상태」로: 2022~2025년만으로 곡선을 만들고 2026년 실제 결과와 비교했습니다.
- 90% 이상으로 나와도 실제는 80% 근처에서 멈춰서 화면에는 「90%+」로만.
- 만점으로도 50%에 못 닿거나 점수로 잘 갈리지 않는(AUC < 0.65) 71개 학부는 「점수 외 요소 큼」 (도쿄대처럼 서류·면접·본고사 비중이 큰 곳).

### 3-6. 한계
- 예측 계수는 2025년 학생으로 만든 것입니다. 2026년 11월 EJU 결과가 나오면 다시 학습합니다.
- 1·2회 모의는 6월 EJU 3~4개월 전이라 「실력 향상분」이 섞여 있습니다.
- 이과 생물은 학습 인원이 10명 안팎이라 신뢰도가 낮습니다.
- 추천은 강사가 고르는 재료입니다. 적성·지역·학비·면접 역량은 모릅니다.
